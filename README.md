# GraalVM `native-image` + Spring Boot (3.4.1) + FlywayDB (10.20.1)

A problem was observed when building a native image using Spring Boot (3.4.1)
and FlywayDB (10.20.1). This repository was created to replicate this problem.

A simple Spring Boot `native-image` example that provides a REST endpoint, which
returns a random quote from an [H2](https://www.h2database.com/html/main.html)
in-memory database by a famous person.

```
GET '/quote/random'
```

This will return a JSON object similar to the following:

```json
{
  "author": "Robert H. Schuller",
  "quote": "Tough times never last but tough people do."
}
```

This example uses a H2 database and
[FlywayDB](https://github.com/flyway/flyway) to manage the database as code.

```xml
        <!-- Database -->
        <dependency>
            <groupId>com.h2database</groupId>
            <artifactId>h2</artifactId>
            <scope>runtime</scope>
        </dependency>
        <dependency>
            <groupId>org.flywaydb</groupId>
            <artifactId>flyway-core</artifactId>
        </dependency>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-data-jpa</artifactId>
        </dependency>
```

The database initialization script will create the table and populate it with
quotes from famous people.

Unfortunately, there is an issue with FlywayDB and the native executable fails
to start with the following error.

```
Caused by: org.graalvm.nativeimage.MissingReflectionRegistrationError: The program tried to reflectively invoke method public boolean org.flywaydb.core.internal.publishing.PublishingConfigurationExtension.isCheckDriftOnMigrate() without it being registered for runtime reflection. Add public boolean org.flywaydb.core.internal.publishing.PublishingConfigurationExtension.isCheckDriftOnMigrate() to the reflection metadata to solve this problem. See https://www.graalvm.org/latest/reference-manual/native-image/metadata/#reflection for help.
    at org.graalvm.nativeimage.builder/com.oracle.svm.core.reflect.MissingReflectionRegistrationUtils.forQueriedOnlyExecutable(MissingReflectionRegistrationUtils.java:83)
```

To address this problem, the following has to be manually added to the
`./META-INF/native-image/reflect-config.json` file.

```json
[
  {
    "name": "org.flywaydb.core.internal.publishing.PublishingConfigurationExtension",
    "queryAllDeclaredMethods": true,
    "allDeclaredFields": true,
    "queryAllDeclaredConstructors": true,
    "methods": [
      {
        "name": "<init>",
        "parameterTypes": [
        ]
      },
      {
        "name": "isCheckDriftOnMigrate",
        "parameterTypes": [
        ]
      },
      {
        "name": "isPublishResult",
        "parameterTypes": [
        ]
      },
      {
        "name": "setCheckDriftOnMigrate",
        "parameterTypes": [
          "boolean"
        ]
      },
      {
        "name": "setPublishResult",

```

## Prerequisites

- [Oracle GraalVM for JDK 21](https://www.oracle.com/java/technologies/downloads/#graalvmjava21)

## Run the example

1. **Build the native executable**

   ```shell
   ./mvnw -Pnative clean native:compile
   ```

   This will take a minute or two to complete.

   (_Optional_) Verify that the JAR files and the native executable were created
   in the `./target` directory:

   ```shell
   tree --charset=ascii --dirsfirst --sort=name -L 1 --prune './target'
   ```

2. **(_Optional_) Run the Java application**

   Run the Java application using the AoT-generated initialization code. This
   helps quickly validate that there are no errors in the AoT-generated code and
   that nothing is missing. You can do this by setting the `spring.aot.enabled`
   system property to `true`. For more information, please refer to the
   [Spring Documentation](https://docs.spring.io/spring-boot/reference/packaging/aot.html).

   ```shell
   java \
     -Dspring.aot.enabled=true \
     -jar './target/graalvm-spring-boot-flywaydb-1.0.0.jar' > './target/output.txt' 2>&1 &
   ```

   Wait for the application to start.

   ```shell
   while [ "$(curl -s -o /dev/null -w '%{http_code}' 'http://localhost:8080/quote/random')" -ne '200' ]
   do
     echo 'Waiting for the application to start'
     sleep 1;
   done
   ```

   Request a random quote.

   ```shell
   curl --silent 'http://localhost:8080/quote/random' | jq
   ```

   This will print a random famous quote similar to the following.

   ```json
   {
     "id": 37,
     "author": "Benjamin Franklin",
     "quote": "Tell me and I forget. Teach me and I remember. Involve me and I learn."
   }
   ```

   Stop the application when ready.

   ```shell
   kill "$(jcmd | grep 'graalvm-spring-boot-flywaydb-1.0.0.jar' | cut -d' ' -f1)"
   ```

4. **Workaround**

   1. Add the required reflection configuration

      For convenience there is a file ready with the required configuration that
      you simply need to rename.

      ```shell
      mv \
        './src/main/resources/META-INF/native-image/omit-reflect-config.json' \
        './src/main/resources/META-INF/native-image/reflect-config.json'
      ```

   2. Rebuild the native executable

      ```shell
      ./mvnw -Pnative clean native:compile
      ```

   3. Run the native executable

      ```shell
      './target/graalvm-spring-boot-flywaydb-1.0.0'  > './target/output.txt' 2>&1 &
      ```

      This time the native executable starts. Wait for the application to start.

      ```shell
      while [ "$(curl -s -o /dev/null -w '%{http_code}' 'http://localhost:8080/quote/random')" -ne '200' ]
      do
        echo 'Waiting for the application to start'
        sleep 1;
      done
      ```

      Request a random quote.

      ```shell
      curl --silent 'http://localhost:8080/quote/random' | jq
      ```

      This will print a random famous quote similar to the following.

      ```json
      {
        "id": 17,
        "author": "Alfred Lord Tennyson",
        "quote": "Hope smiles from the threshold of the year to come, whispering \"it will be happier.\""
      }
      ```

      Stop the application when ready.

      ```shell
      pkill -f 'graalvm-spring-boot-flywaydb-1.0.0'
      ```
